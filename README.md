# Projeto de Luta

Projeto desenvolvido durante meus estudos de JavaScript, com o objetivo de praticar a criação de personagens e a implementação de um sistema de combate.

## Versões

O projeto possui duas implementações:

- **Programação Funcional:** criação de personagens e organização da lógica utilizando funções e objetos.
- **Programação Orientada a Objetos (POO):** utilização de classes, herança, construtores, getters e setters.

## Funcionalidades

- Criação de personagens com atributos próprios.
- Sistema de ataque e defesa com valores aleatórios.
- Atualização dinâmica das barras de vida.
- Histórico de ações durante o combate.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Conceitos praticados

- Manipulação do DOM.
- Funções e objetos.
- Classes e herança.
- Getters e setters.
- Spread operator.
- Eventos e arrays.
